# 多方块搭建

存储系统、计算系统、合成系统和大型集成工作站，使用结构全息投影仪辅助搭建。

## 搭建步骤

1. 放下控制器，确认正面朝向。
2. 手持结构全息投影仪右键控制器，查看投影。
3. 准备结构材料，潜行右键控制器进行搭建。
4. 生存模式会从物品栏取用材料，可重复操作直到完成。
5. 完成后打开控制器，确认结构已成型。

缺料时补齐材料再继续。投影位置被其他方块占用时，需要先清理。

## 调整长度

可扩展结构使用投影仪的堆叠数量选择长度。更长的结构可在投影仪设置中配置长度通道；镜像结构通过镜像通道选择。

扩建时应一并补齐对应的核心、驱动器和外壳。长度上限以当前服务器配置为准。

## 查看材料

安装对应多方块预览功能后，可以在物品管理器中查看结构和材料清单。

结构没有成型时，优先检查朝向、末端部件、部件等级及是否缺少外壳。
