## 中文

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 新增与改进

- 合成子系统 FD 智能样板总线接入 AE2 原生接口终端，暴露原有 63 槽样板库存，并支持合成样板提供者筛选。
- 大型集成工作站接入 ECO 样板自动上传，复用工作站现有配方兼容校验与样板库存，遵守容量升级所解锁的槽位。
- 无限存储的超大数量计数与汇总改用无符号分段数组，并补充相关上游许可声明。
- 新增独立的 ECO 原生成就页，包含 7 项成就及多语言文本。
- ECO 驱动器支持管道、漏斗插拔存储元件，遵守现有元件校验与提取锁定规则。
- 新增网络拉取卡，流体输入仓可按过滤条件从 ME 网络补货，并回存超额流体。
- 优化存储接口增量传输、网络库存快照与规划器集合；规划重试复用已有结果，并保留精确库存数量。
- 完善合成报告摘要及 AE2 原生计划统计，统一最终方案发布，优化合成状态同步和产物回流。

### 修复

- 修复合成通讯接口样板预览的输入、输出搜索同步，按客户端语言匹配物品名称，并增加搜索中提示。
- 自动上传目标列表遵守接口终端可见性设置，上传前重新检查目标可见性、在线状态及工作站结构，避免向隐藏或失效目标写入样板。
- 样板上传在多个等价接收端间选择空槽；目标已满时顺延或溢出，失效的自动绑定恢复正常选择，ECO 样板域增减总线后仍保留有效绑定。
- 修复破坏存储驱动器和存储主机时内部元件未掉落，以及合成提交失败回滚时剩余物品丢失的问题。
- 清理已释放合成 CPU 的通知注册，保留离线完成通知，并在确认页关闭时清理合成图缓存。
- 修复合成确认页提示重叠、框架碰撞箱、极寒冷却材料兼容及指南结构材料统计。

### 1.7.10 适配说明

- 不注册配方书解锁进度；高炉配方使用已有的熔炉对应配方。
- 盈能水晶沿用 GT 机器配方，不移植种植与雷击转化；矿产由 GTNH 矿脉提供。

## English

Minecraft 1.7.10 / GTNH. Supports **GTNH 2.9.0-RC1 and later**.

### Added and improved

- Integrated the crafting subsystem's FD Smart Pattern Bus with AE2's native interface terminal, exposing its existing 63 pattern slots and supporting the crafting-provider filter.
- Added the ECO Large Integrated Workstation as an automatic pattern upload target, reusing its existing recipe compatibility checks and pattern inventory while respecting capacity upgrades.
- Switched large-quantity counting and aggregation in infinite storage to unsigned segmented arrays and included the upstream license notice.
- Added a dedicated native ECO achievement page with seven achievements and localized text.
- ECO Drives now support cell insertion and extraction through pipes and hoppers, respecting existing cell validation and extraction locks.
- Added the Network Pull Card so fluid input hatches can replenish filtered fluids from ME storage and return excess fluid.
- Improved incremental storage-interface transfers, network inventory snapshots, and planner collections. Planning retries reuse previous results while preserving exact inventory amounts.
- Expanded crafting report summaries and AE2 native plan statistics, unified final plan publication, and improved crafting status synchronization and output return.

### Fixed

- Fixed input and output search synchronization in the crafting interface's pattern preview. Item names are matched in the client's language, with a searching indicator while results are pending.
- Automatic upload discovery now respects interface terminal visibility settings. Uploads recheck target visibility, online state, and workstation structure before writing patterns.
- Pattern uploads select available slots across equivalent targets, continue to another tier or receiver when full, recover from invalid automatic bindings, and preserve valid ECO pattern-domain bindings when buses change.
- Fixed missing contents when storage drives and hosts are broken, and retained items that cannot be returned during a failed crafting submission rollback.
- Cleaned up notification registrations for released crafting CPUs while retaining offline completion notifications, and cleared cached crafting graphs when the confirmation window closes.
- Fixed overlapping confirmation tooltips, frame collision boxes, cryotheum coolant compatibility, and guide structure material counts.

### 1.7.10 adaptation notes

- Recipe-book unlock advancements are omitted; blasting recipes use their existing smelting counterparts.
- Energized crystals retain GT machine recipes without crystal farming or lightning conversion. Ore generation remains supplied by GTNH.
