## 中文

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 新增与改进

- **样板上传系统全面升级**：围绕机器类别、电路选择、配方来源与具体接收端重整自动上传流程，改进目标识别、绑定管理及状态提示。
- 样板自动上传支持按玩家保存机器类别及电路对应的具体接收端绑定，提供修改、停用、启用和删除操作；多个独立接收端存在歧义时要求明确选择，绑定目标失效时不会自动改投其他接收端。
- 改进 GT 加工样板的机器类别、电路及 NEI 配方来源识别，结合已成型机器的当前路线和输入端能力筛选目标；补充路线歧义、流体输入不兼容及未验证路由的提示。
- 接入 NotEnoughEnergistics 多材料补料，将材料需求合并为 ECO 临时订单，并适配工作站快捷操作。
- 存储控制器支持 NEI 书签取料及配方链库存查询。
- 合成确认页新增“重新规划”操作，便于更新当前合成报告。
- 重整中文入门指南，加入原生单方块、多方块结构预览并修正导航。

### 修复

- 修复 NEI 覆盖层及嵌套配方界面切换导致合成界面状态丢失的问题。
- 修正 NEI 填充、样板编码和重新载入样板时的配方来源生命周期，避免沿用其他样板的来源信息。
- 统一通道样板输入展开和 GT 加工样板识别，补充无效、循环引用及数量溢出提示。
- 保留原生合成网格尺寸与槽位，修复裁剪后配方匹配异常。
- 统一合成产物交付判断，在产物无法交付时显示状态页提示。
- 记录实际加工派发来源，优先刷新当前物品的机器详情。
- 将无限存储快照纳入原版存盘队列，合并尚未执行的同文件快照并优化压缩读写。
- 流体输入输出仓配方改用 AE2FC 流体总线作为材料。

### 内容调整

- 清理自动测试源码、依赖及开发辅助运行入口。
- 客户端与服务端请同步更新，升级前请备份存档。

## English

Minecraft 1.7.10 / GTNH. Supports **GTNH 2.9.0-RC1 and later**.

### Added and improved

- **Major pattern upload system upgrade**: reworked automatic upload around machine categories, circuit selections, recipe sources, and individual receivers, with improved target recognition, binding management, and status messages.
- Pattern upload now saves per-player bindings from machine categories and circuit selections to individual receivers, with edit, disable, enable, and delete actions. Ambiguous receivers require an explicit choice, and missing bound receivers do not cause automatic redirection.
- Improved GT processing pattern recognition using machine categories, circuits, NEI recipe sources, formed machines' active routes, and input capabilities. Added explanations for ambiguous routes, incompatible fluid inputs, and unverified routing.
- Integrated NotEnoughEnergistics requests for multiple materials into temporary ECO crafting orders, with workstation shortcut support.
- Storage controllers now support NEI bookmark extraction and recipe-chain stock queries.
- Added a replan action to the crafting confirmation screen to refresh the current report.
- Reworked the Chinese introductory guide with native block and multiblock previews and corrected navigation.

### Fixed

- Fixed crafting screen state being lost when switching through NEI overlays and nested recipe screens.
- Corrected recipe-source tracking during NEI transfers, pattern encoding, and pattern loading to avoid reusing another pattern's source.
- Unified tunnel-pattern input expansion and GT processing pattern recognition, with messages for invalid definitions, cyclic references, and quantity overflow.
- Preserved native crafting grid dimensions and slots to fix recipe matching after grid trimming.
- Unified crafting output delivery checks and added a status warning when outputs cannot be delivered.
- Recorded actual processing dispatch sources and prioritized machine details for the selected item.
- Integrated infinite-storage snapshots with Minecraft's save queue, coalesced pending snapshots for the same file, and improved compressed I/O.
- Changed fluid input/output hatch recipes to use AE2FC fluid buses.

### Content changes

- Removed automated test sources, dependencies, and development acceptance entry points.
- Update both client and server, and back up saves before upgrading.
