# Neo ECO AE Extension 7.3.2

官方 Minecraft 1.7.10 / GTNH 版本，支持 **GTNH 2.9.0-RC1 及以上版本**。

## 更新内容

- 修复铝、铝合金、钨和黑钨合金系列共 20 件工具名称多出 `.name` 的问题，统一斧、锄、镐、锹和剑的名称翻译。
- 移除 LE4、LE6、LE9 大宗物品存储矩阵及其外壳，同时清理装配与拆解配方、专用模型、贴图和相关处理逻辑。普通物品、流体存储矩阵继续保留。
- 多方块搭建接入 StructureLib 全息投影仪，并提供 NEI 结构预览。
- 新增基于 GTNHLib 的游戏内配置界面，存储盘模糊过滤接入 AE2 原生实现。
- 同步存储盘优先级、GT 加工监控与 NEI 路线显示，补齐 `7.3.0-beta1` 存储升级兼容。
- 整理界面组件、语言显示和 README，并将开发验收代码移出正式运行包。

## 升级说明

大宗矩阵及外壳不再注册，旧盘不会自动转换。升级前请先在旧版本中将大宗矩阵内的库存转移到普通存储，并备份存档。

从 `7.3.0-beta1` 升级时，请阅读 [存储升级兼容说明](../STORAGE_7_3_0_BETA_COMPATIBILITY_ZH_CN.md)。该兼容层迁移存储系统，旧合成与计算设备需要按新版重新搭建。

## 下载文件

- `neoecoae-7.3.2.jar`：游戏运行包，安装到客户端和服务端的 `mods` 目录。
- `neoecoae-7.3.2-dev.jar`：开发依赖包。
- `neoecoae-7.3.2-sources.jar`：源码包。
- `SHA256SUMS.txt`：以上三个文件的 SHA-256 校验值。
