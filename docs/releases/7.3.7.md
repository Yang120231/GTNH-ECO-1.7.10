## 中文

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 新增与优化

- 大型集成工作站支持 CraftTweaker 自定义配方及脚本重载。
- 合成状态页新增独立任务栏，优化任务排序、滚动与状态提示。

### 修复

- 修复同网络跨维度 ECO CPU 无法接收合成订单的问题。
- 恢复原生 AE2 缺料计划的 Shift 强制下单。
- 修复计算主机挖掘后重新出现及重复掉落的问题。
- 修复 GTNH 2.9.0 样板上传按钮重叠。
- 修复循环合成共享库存与超大数量预留的问题。
- 补充两种盈能水晶的 GT 研磨配方和超导处理器印刷电路的成型机配方。

### 内容调整

- 移除盈能水晶母岩、晶芽、晶簇及对应水中转化配方，更新水晶获取指南。
- 客户端与服务端请同步更新，升级前请备份存档。

## English

Minecraft 1.7.10 / GTNH. Supports **GTNH 2.9.0-RC1 and later**.

### Added and improved

- Added CraftTweaker custom recipes and script reload support for the Large Integrated Workstation.
- Added a separate task column to crafting status screens and improved task ordering, scrolling, and status tooltips.

### Fixed

- Fixed ECO CPUs rejecting orders from another dimension on the same network.
- Restored Shift force-start for native AE2 plans with missing materials.
- Fixed computation hosts reappearing after mining and dropping duplicate items.
- Fixed overlapping pattern upload buttons in GTNH 2.9.0.
- Fixed shared stock and large-quantity reservations in cyclic crafting.
- Added GT macerator recipes for both energized crystal types and a forming press recipe for printed superconducting circuits.

### Content changes

- Removed energized crystal budding blocks, buds, clusters, and their water transformation recipes. Updated the crystal acquisition guide.
- Update both client and server, and back up saves before upgrading.
