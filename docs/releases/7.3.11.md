## 中文

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 改进

- 加工样板按剩余需求自适应翻倍发配，减少大批量加工的重复派发开销。
- 移除普通加工样板与接收端的类名白名单，扩展批量投料适用范围，同时保留特殊执行语义样板的排除规则与数量限制。
- 完善普通可编程样板仓、倍增加工样板、AE2 终极样板及流体加工样板的批量投料兼容。

### 修复

- 分离优先配方与后续候选配方的扫描游标，修复优先配方持续接收时后续配方长期无法被扫描的问题。

## English

Minecraft 1.7.10 / GTNH. Supports **GTNH 2.9.0-RC1 and later**.

### Improved

- Processing pattern dispatch now adaptively doubles batch sizes according to remaining demand, reducing repeated dispatch overhead for large processing jobs.
- Removed class-name allowlists for ordinary processing patterns and receivers to support batching more broadly, while retaining exclusions for patterns with special execution semantics and quantity limits.
- Improved batch input compatibility for ordinary Programmable Pattern Hatches, multiplied processing patterns, AE2 ultimate patterns, and fluid processing patterns.

### Fixed

- Separated scan cursors for preferred recipes and subsequent candidates, fixing subsequent recipes being left unscanned while preferred recipes continuously accept inputs.
