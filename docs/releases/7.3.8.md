## 中文

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 修复

- 修复玩家合成任务误显示为机器请求的问题，保存并恢复实际请求者名称。
- 修复合成树截图错误导出材料列表的问题；树模式按当前展开、折叠与筛选状态导出树图，采用 GTNH 风格的双倍分辨率与分块渲染。
- 修复 GTNH 耗能倍率计算中的浮点误差导致部分含流体配方无法执行的问题，统一普通批量与超大数量订单的耗能检查，并保留实际缺电时的数量限制。
- 修复合成 CPU 接收物品时将其误计为网络库存，以及样板刷新时错误累加库存的问题；相关变化会使缓存重新读取实际库存。
- 修复合成状态界面物品渲染状态泄漏，避免影响 NEI 物品显示。
- 合成预览、规划图及 CPU 页面的流体数量统一采用 NH 的升（L）口径，不再将显示数量除以 1000；底层数量、能耗与合成计算保持不变。

### 内容调整

- 客户端与服务端请同步更新，升级前请备份存档。

## English

Minecraft 1.7.10 / GTNH. Supports **GTNH 2.9.0-RC1 and later**.

### Fixed

- Fixed player crafting jobs being shown as machine requests. The actual requester's name is now saved and restored.
- Fixed crafting tree screenshots exporting the material list. Tree mode now exports the current expanded, collapsed, and filtered tree using GTNH-style double resolution and tiled rendering.
- Fixed floating-point rounding in GTNH's energy multiplier preventing some fluid-containing recipes from running. Ordinary batches and very large orders now share energy affordability checks while retaining limits for actual energy shortages.
- Fixed items accepted by crafting CPUs being counted as stored network stock, and pattern refreshes incorrectly increasing cached stock. These changes now trigger a rebuild from the actual inventory.
- Fixed item rendering state leaking from the crafting status screen and affecting NEI item rendering.
- Fluid quantities in crafting previews, planning graphs, and CPU pages now use NH's liter (L) convention instead of dividing displayed amounts by 1,000. Internal quantities, energy costs, and crafting calculations are unchanged.

### Content changes

- Update both client and server, and back up saves before upgrading.
