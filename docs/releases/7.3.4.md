## 中文

### 新增

- 新增 ECO 合成状态界面，集中展示 CPU、任务库存、循环成员和关联机器的加工明细，包括实际并行、加工进度与剩余时间。
- 合成状态条目支持右键定位并高亮样板、打开关联机器和样板供应器，多目标可通过分页列表选择。
- 完善 GT 机器状态诊断，显示停机、禁用、维护、缺电、输出堵塞、结构未成型等原因。
- 同产物请求支持合并到正在执行的原生任务，并补充材料、任务存储与待回收产物的合并处理。

### 修复

- 修复循环合成为保留启动种子而额外增加加工次数的问题；库存中的中间原料按实际需求消耗。
- 兼容可编程舱室的空输入样板，修复 `Invalid native pattern stack` 导致服务器崩溃的问题。
- 修复网络样板迁移和一键整理，支持按主产物排序、回收重复样板，并显示迁移与整理结果。
- 修复上传界面中的 GT 机器名称因虚拟电路后缀显示为语言键的问题。
- 修复原生面板悬停背景、NEI 侧栏遮挡及部分界面文字布局问题。

### 调整与优化

- 成功派发的配方保持连续处理优先级，减少供料充足时的加工中断；预算暂停后可在下一 tick 继续派发。
- 加工批量预算改按接口提交次数计算，每个 CPU 每 tick 最多提交 64 次、单个配方最多 32 次，移除每 tick 百万份限制。
- 存储元件统一按 L4、L6、L9 命名；CE4、CE6、CE9 闪存晶阵容量分别提升至 256 MiB、1 GiB、4 GiB。
- 存储元件、闪存晶阵、无限存储组件和无限物品元件配方的物品、流体及能量投入翻倍；GT 电路与功能部件按 IV、LuV、ZPM 分级，无限元件提升至 UHV，并调整 AE 存储组件需求。
- 统一控制器标题字号，优化 CPU 列表的容量缩写、悬停信息与整格进度填充。
- 更新 AE2、AE2FC、ModularUI2、GTNHLib、GuideNH、StructureLib 和 GT 依赖，对齐 GTNH 2.9.0，并补齐无线合成终端运行依赖。
- 更新中英文 README，加入对应语言的功能截图与精简说明。

## English

### Added

- Added an ECO crafting status screen showing CPUs, job inventory, cycle members, and associated machines, including actual parallels, processing progress, and remaining time.
- Added context actions to locate and highlight patterns, open associated machines, and open pattern providers, with paginated selection for multiple targets.
- Expanded GT machine diagnostics with shutdown, disabled, maintenance, power shortage, blocked output, and unformed structure states.
- Added merging of requests for the same output into running native jobs, including materials, job storage, and pending output accounting.

### Fixed

- Fixed cyclic crafting adding extra processing steps just to retain startup seeds. Existing intermediate materials are consumed according to actual demand.
- Added support for Programmable Hatches patterns with empty inputs, fixing server crashes caused by `Invalid native pattern stack`.
- Fixed network pattern migration and one-click organization, with sorting by primary output, duplicate pattern recovery, and operation results.
- Fixed GT machine names appearing as translation keys in the upload screen when a virtual circuit suffix is present.
- Fixed native panel hover backgrounds, NEI sidebar overlap, and text layout issues.

### Changed and Improved

- Successfully dispatched recipes retain processing priority, reducing interruptions when materials remain available and resuming dispatch on the next tick after a budget pause.
- Processing budgets now count interface submissions: up to 64 per CPU per tick and 32 per recipe. Removed the previous million-craft per-tick limit.
- Renamed storage components by L4, L6, and L9 tier. Increased CE4, CE6, and CE9 flash array capacities to 256 MiB, 1 GiB, and 4 GiB respectively.
- Doubled item, fluid, and energy costs for storage components, flash arrays, infinite storage components, and infinite item cells. Adjusted GT circuits and functional parts to IV, LuV, and ZPM, raised infinite components to UHV, and updated AE storage component requirements.
- Standardized controller title sizes and improved CPU list capacity abbreviations, tooltips, and full-cell progress fills.
- Updated AE2, AE2FC, ModularUI2, GTNHLib, GuideNH, StructureLib, and GT dependencies for GTNH 2.9.0, and added the wireless crafting terminal runtime dependency.
- Updated the Chinese and English READMEs with localized feature screenshots and concise descriptions.
