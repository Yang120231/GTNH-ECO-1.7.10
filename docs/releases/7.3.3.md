# Neo ECO AE Extension 7.3.3

Minecraft 1.7.10 / GTNH 版本，支持 **GTNH 2.9.0-RC1 及以上版本**。

本次为 7.3.3 修正版重发，调整工作站流体配方的样板写入方式，并将 AE2 Fluid Crafting（AE2FC）改为必需前置。已下载旧版 7.3.3 的用户请重新下载并替换同名 JAR，客户端与服务端均需更新。

## 更新内容

- 工作站配方直接通过 AE2 原生样板槽同步写入物品与流体，保留实际物品数量与 mB 数量，支持纯流体输出及物品、流体混合输出。
- 样板写入先同步处理模式，再提交配方，避免服务端仍按合成模式处理时丢弃流体或将物品数量缩减为 1；槽位不足时保留原有样板内容。
- 将 AE2FC 改为硬依赖，流体展示与传输使用 AE2FC 流体包，移除工作站对 NotEnoughEnergistics 转换逻辑的依赖。
- 重做 ECO 合成确认界面，整合 CPU 选择、材料排序与搜索、库存使用比例、合成次数、界面尺寸切换，以及开始并跟踪、缺料加入 NEI 书签和保存图片等操作。
- 新增合成计划树，可在材料列表与计划树之间切换，支持拖动、缩放、展开与收起、深度切换、仅看缺料和搜索定位。
- 开启快速规划时，交由 AE2 原生规划器计算的请求也可在 ECO 确认界面中查看材料和计划树，并通过原生流程提交任务。
- 样板上传改为可拖动浮窗，支持分组查看目标、右键定位机器，上传后返回样板终端；恢复 AE2 风格的上传按钮并调整按钮位置。
- 对齐 GTNH 原版 CPU 的合成发配行为，完善虚拟合成卡与多类型目录流体样板支持，GT 样板总成可一次推送全部所需份数。
- ECO 界面支持 Shift / NEI 快速转移，大集成工作站接口支持潜行右键安装升级卡。

## 升级说明

必需前置包括 Applied Energistics 2、AE2 Fluid Crafting（AE2FC，1.5.64-gtnh 及以上）、ModularUI2 和 StructureLib。

客户端与服务端请一并更新至本次重发的 7.3.3。版本号保持不变，已安装旧版 7.3.3 的用户也需替换运行包；升级前请备份存档。本版同时包含此前 7.3.3 的合成确认数据同步格式调整。

## 下载文件

- `neoecoae-7.3.3.jar`：游戏运行包，放入客户端与服务端的 `mods` 目录。
- `neoecoae-7.3.3-dev.jar`：开发依赖包。
- `neoecoae-7.3.3-sources.jar`：源码包。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

## 验证情况

本次重发通过离线 `check assemble`，包括 Spotless、Checkstyle、1002 项常规测试（5 项跳过、零失败）和 1 项发布 JAR 库存兼容测试。新增回归测试覆盖混合输出、纯流体输出、数量保持、处理模式同步顺序，以及槽位不足时保留原样板。已核验包内版本号、AE2FC 硬依赖与运行依赖配置，开发验收源码集未进入运行包。本次未进行游戏内验收。
