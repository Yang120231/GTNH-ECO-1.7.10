## 中文

Minecraft 1.7.10 / GTNH，支持 **GTNH 2.9.0-RC1 及以上版本**。

### 新增与改进

- 样板上传界面增加维度与状态筛选、同类机器分组、目标数量及槽位统计、独立定位按钮，并支持在本次游戏会话中调整窗口高度。
- 上传目标显示实际接收机器的供电电压等级，支持按电压等级分组与搜索。等价可用目标按电压等级、空槽数量及可编程电路能力排序。
- 保存并恢复玩家的 NEI 配方来源；配方改动后保留来源类别，完善绑定范围与拒绝原因提示。
- 统一工作站、算力与 CPU 状态卡片，补充温度、冷却、能源、加工进度和阻塞原因；原生与 Lite 合成规划显示实际计算耗时。
- 大型工作站接口支持编辑优先级，以滚动槽位展示样板和升级卡，并退还旧版第五格升级卡。
- NEI 支持只读查看有限 ECO 存储元件的内容、已用容量和类型数量，保留物品与流体的精确数量显示。
- 新增 L4、L6、L9 计算元件拆解配方，分别返还 8 个 16M、64M、256M 存储组件。
- 加工监控识别 GT 与 GTNL 样板输入镜像共享的机器，沿用现有扫描预算，并补充每并行产出与本轮产出提示；无法确定的并行数继续显示未知。

### 修复

- 自动上传优先使用已验证路线，避免未验证、离线或无法完整检查的其他目标阻断有效路线；完善可编程目标、固定电路和等价接收端的选择。
- 显式绑定继续指定接收端，自动记忆的目标随正常排序更新；满槽目标可回退到可用目标，并统一重复样板检查。
- 修复打开上传菜单时丢失撤销状态，以及搜索框缩放、鼠标坐标、列表滚动条和工作站接口边框问题。
- 工作站样板变更在服务端 Tick 结束时合并通知，复用 AE2 的接口按网络合并目录重建；忽略内容未变的重复写入，保留原地 NBT 编辑及节点状态变化的刷新。
- 大型工作站的冷却液、温度与批次变化不再触发 AE2 合成目录重建。
- 修复工作站流体槽容量同步与液面越界，以及温度、冷却提示中的百分号格式。
- 修复接口样板缓存绕过优化开关的问题，统一接口宿主与合成锁的批量投料判定。

工作站目录刷新与加工监控的部分思路参考 salieelinar 分支的 `b2d49ca`、`25c1094`、`f2909db` 与 `e927657`，并调整库存回调判定、刷新合并和扫描预算。

## English

Minecraft 1.7.10 / GTNH. Supports **GTNH 2.9.0-RC1 and later**.

### Added and improved

- Added dimension and status filters, machine grouping, target and slot statistics, dedicated location buttons, and session-persistent window height controls to pattern upload.
- Upload targets show the actual receiving machine's supply voltage tier, with tier grouping and search. Equivalent available targets are ranked by voltage tier, free slots, and circuit programming capability.
- Preserve and restore NEI recipe sources, retain source categories after recipe edits, and improve binding scopes and rejection messages.
- Unified workstation, computation, and CPU status cards, with temperature, cooling, energy, processing progress, and blocking reasons. Native and Lite crafting planners now show measured calculation time.
- Added priority editing and scrollable pattern and upgrade slots to the large workstation interface. The former fifth upgrade slot returns its card.
- Added a read-only NEI view of finite ECO storage cells, including contents, used capacity, type counts, and exact item and fluid amounts.
- Added disassembly recipes for L4, L6, and L9 computation cells, returning eight 16M, 64M, and 256M storage components respectively.
- Processing monitoring recognizes machines shared by GT and GTNL pattern input mirrors within the existing scan budget. Tooltips include output per parallel operation and per batch; unavailable parallel counts remain unknown.

### Fixed

- Auto-upload prefers verified routes, preventing unrelated unverified, offline, or incompletely inspected targets from blocking valid routes. Improved selection of programmable targets, fixed circuits, and equivalent receivers.
- Explicit bindings retain their selected receivers, while automatically remembered targets follow normal ranking. Full targets can fall back to available receivers, with consistent duplicate pattern detection.
- Fixed lost undo state when opening the upload menu, search scaling and mouse coordinates, list scrollbars, and workstation interface borders.
- Workstation pattern changes are coalesced at the end of the server tick and use AE2's interface mechanism to merge catalog rebuilds per network. Unchanged writes are ignored while in-place NBT edits and node state changes still refresh the catalog.
- Coolant, temperature, and batch changes in large workstations no longer rebuild the AE2 crafting catalog.
- Fixed workstation fluid capacity synchronization and overflowing fluid rendering, plus percent formatting in temperature and cooling tooltips.
- Fixed interface pattern caches bypassing the optimization setting and aligned batch dispatch checks for interface hosts and crafting locks.

Parts of the workstation catalog refresh and processing monitoring improvements draw on salieelinar's commits `b2d49ca`, `25c1094`, `f2909db`, and `e927657`, with adjusted inventory callbacks, refresh coalescing, and scan budgets.
