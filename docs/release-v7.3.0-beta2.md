# v7.3.0-beta2

## 新增与完善

- 新增手动发布和版本标签自动发布流程，构建通过后自动上传 JAR；带 beta 等后缀的版本标记为预发布。
- 完善存储、计算、合成三大主机界面，统一标题、侧栏排列和按钮尺寸。
- 主机按钮新增按压下移反馈，图案缩小并居中，改善按钮视觉一致性。
- 存储主机提供唯一的优先级入口，直接打开 AE2 原生优先级设置，并支持返回主机界面。
- 补充存储、计算、合成系统的方块与 GUI 纹理资源；部分资源为后续兼容状态准备，不代表新增对应机器功能。

## 调整与修复

- 合成计算、排序、确认及提交恢复使用 GTNH AE2 原生流程，移除过渡版 ECO 规划器及报告页面。
- 保留并整理 ECO 批量合成加速、输入回滚、能量预留与执行归属恢复逻辑。
- 计算和合成主机移除问号、搭建入口，保留 CPU 模式、超频、主动冷却和网络频率等适用操作。
- 整理驱动器渲染实现及测试运行依赖。

## 下载与验证

- 游戏使用不带 -dev、-sources 后缀的 JAR，适用于 Minecraft 1.7.10 / GTNH 环境。
- 本地完整 Gradle build、测试、Checkstyle 和 Spotless 检查通过。
- 此版本为 Beta，尚未完成所有界面的游戏内视觉与交互验收。
