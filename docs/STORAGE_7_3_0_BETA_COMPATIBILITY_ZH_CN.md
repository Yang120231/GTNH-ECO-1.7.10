# 7.3.0-beta 存储升级兼容

兼容基准是本仓库标签 `v7.3.0-beta1`（`c45230645ead42faf7deba1d209a37ee1a842e0e`）实际写出的格式。

## 读取与迁移

- 普通物品、流体存储元件：读取物品根 NBT 的 `ECOStorage.entries`，转换资源注册名、损伤值、Base64 压缩 NBT 和数量。流体保持 mB 单位。
- 无限存储：按控制器原 UUID，从主世界 `data/neoecoae_storage_domains.dat` 的 `data.domains` 读取对应域；数量继续使用精确大整数。
- 方块实体：保留 `neoecoae:eco_controller`、`neoecoae:eco_drive`、`neoecoae:eco_interface` 的加载入口。世界加载后根据原位置的存储方块选择实际实体类型，恢复控制器域、成员标识、无限组件、优先级、朝向、接口模式和驱动器的 `Cell`。
- 中断的入库迁移：保留旧磁盘 UUID 和 `committedSources`；已经入库的磁盘只清理旧源，不再重复导入。
- 中断的退出无限模式：旧 `Completed` 尚未提交时，域仍拥有全部资源，磁盘仍封存；从该域按当前恢复协议继续。已提交完成的恢复，则从旧计划恢复尚未解除封存的磁盘快照。

## 数据保留规则

旧磁盘的 `ECOStorage` 和旧域文件保持原样。首次实际修改内容时，写入当前格式；取空也写入明确的空库存，防止再次导入旧快照。当前域文件已经存在时，继续以当前域文件为准，不回退读取旧快照。

无法解析的普通磁盘或无限存储组件不会当作空槽加载。无法读取的旧域会标记不可用并保留原文件。存储方块实体转换失败时保留完整原始 NBT，并阻止玩家拆除或实体、爆炸破坏该过渡方块；修复依赖后重载区块可重试。

该补丁只迁移存储系统。旧版共用控制器、接口 ID 中的合成、计算子系统方块保留原始 NBT 但保持停用，并在日志中提示一次；它们不受拆除保护，拆除重放即可得到新方块（旧数据随之丢弃）。旧版 `computation_drive`、`crafting_pattern_bus`、`crafting_worker`、`crafting_hatch`、`network_switch` 方块实体 ID 没有别名，加载时会被 FML 跳过。该兼容层不能恢复已经被不兼容版本覆盖或删除且没有备份的数据。

## 验证

`BetaStorageCompatibilityTest` 覆盖物品变体、流体变体与单位、只读操作、取空及重载、无限域大整数与磁盘去重回执、异常快照和中断入库。`BetaStorageTileTest` 覆盖旧 ID 实际加载、区块未就绪时原始 NBT 保留、按方块选择控制器等级和转换失败保留。

单元测试、编译和 JAR 构建不等于真实旧存档升级验收。发布前应使用 `v7.3.0-beta1` 存档副本核对普通盘及无限域的完整资源清单，并在保存、退出和重新载入后再次比对。
